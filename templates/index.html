How do I get a GitHub Token?
  1. Go to github.com/settings/tokens (or select Settings → Developer Settings → Personal Access Tokens → Tokens classic).
  2. Click Generate new token → select Generate new token (classic).
  3. Name the token and choose scopes: check repo (all scopes) and workflow.
  4. Scroll to the bottom, click Generate token, and copy the token starting with ghp_!
